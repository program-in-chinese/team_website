
[此答被折叠](https://www.zhihu.com/question/1965786839827854197/answer/1973021573339428510)后，就着手试用litex。[在线环境](https://litexlang.com/playground) 运行：

```
let 快乐宝贝 set
let 小怪, 大怪, 老怪, 快乐超人 快乐宝贝

# 传递性
prop 领导(x, y 快乐宝贝)
know 大怪 $领导 小怪, 老怪 $领导 大怪
prop 层层领导(x, y, z 快乐宝贝):
    x $领导 y
    y $领导 z
    <=>:
        x $领导 z
know forall x, y, z 快乐宝贝: x $领导 y, y $领导 z => $层层领导(x, y, z)
$层层领导(老怪, 大怪, 小怪)
老怪 $领导 小怪

# 可交换性
prop 敌对(x, y 快乐宝贝)
know forall x, y 快乐宝贝 => x $敌对 y <=> y $敌对 x; 快乐超人 $敌对 大怪
大怪 $敌对 快乐超人

# 自反性
prop 友好(x, y 快乐宝贝)
know forall x 快乐宝贝 => x $友好 x
小怪 $友好 小怪
```
